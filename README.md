# FastAPI Excel to SQL Anywhere API

API desarrollada en Python utilizando FastAPI para automatizar la lectura de archivos Excel y la inserción masiva de registros en una base de datos SQL Anywhere 17.

## 🚀 Tecnologías utilizadas
* **Python**
* **FastAPI**
* **SQL Anywhere 17**
* **Pandas**

## 📌 Próximas mejoras pendientes
* Implementar autenticación con JWT.
* Manejo avanzado de excepciones y validaciones de datos del Excel.
